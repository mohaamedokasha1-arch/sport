# NEMO Sports — لوحة التحكم (Admin Panel)

## الوصول
- `/admin/login` — تسجيل الدخول (اسم المستخدم + كلمة المرور). كلمات المرور مُشفّرة بـ bcrypt (cost 12).
- كل مسارات `/admin/*` و`/api/admin/*` محمية في `middleware.ts`، وكل صفحة/إجراء يعيد التحقق من
  الحساب والدور في قاعدة البيانات (`requirePermission`)، فتعطيل الحساب أو تغيير دوره يسري فورًا.
- الجلسة: كوكي `httpOnly` موقّع بـ HMAC، مدتها 12 ساعة، وتحمل هوية المشغّل والدور فقط (لا كلمات مرور).
- حماية من التخمين: حد 8 محاولات فاشلة لكل IP خلال 15 دقيقة (في ذاكرة العملية).
- لوحة التحكم غير قابلة للفهرسة (`noindex`) ومستبعدة من `robots.txt` و`sitemap.xml`.

## الأدوار (RBAC)
| الدور | الصلاحيات |
|---|---|
| Super Admin | كل شيء، بما فيها المستخدمون وإعدادات الموقع |
| Admin | المباريات، البث، الأخبار، الفرق، اللاعبون، البطولات، الترتيب، النواقل، المزوّدون، السجل |
| Editor | المباريات، البث، الأخبار، السجل فقط |

## الإعداد
```
DATABASE_URL=postgres://…           # مطلوب لحفظ دائم وتعدد المستخدمين
ADMIN_USERNAME=admin                # أول حساب super admin
ADMIN_PASSWORD_HASH=…               # npm run admin:hash -- '<كلمة مرور 12+ حرفًا>'
ADMIN_SESSION_SECRET=…              # مفتاح توقيع الجلسات (openssl rand -hex 32)
```
بدون `DATABASE_URL` تعمل اللوحة بتخزين مؤقت في الذاكرة (يُفقد عند إعادة التشغيل)، ويُعرض ذلك صراحةً في الواجهة.

## سير عمل البث المباشر
`البث المباشر` ← `+ إضافة بث` ← اختيار المباراة ← نوع البث ← رابط Embed ← `معاينة` ← `حفظ كمسودة` / `نشر`.

- الرابط يجب أن يكون `https` ومن نطاق رسمي معتمد في `lib/broadcasts.ts` (`OFFICIAL_BROADCAST_DOMAINS`). أي رابط آخر يُرفض.
- لا يُقبل أي كود HTML أو سكربت داخل الحقل.
- الحالات: مسودة (لا تظهر للزوار) · منشور · بث حي · منتهٍ · موقوف. الإيقاف والإنهاء لا يحذفان البيانات.
- الحذف يزيل ارتباط البث فقط؛ المباراة نفسها لا تُمس.
- زر «إيقاف النشر» في إعدادات الموقع يوقف نشر أي بث جديد فورًا.
- البث المنشور يظهر في `/live` وفي صفحة المباراة المرتبطة به.

## المحتوى المنشور من اللوحة
- **المباريات**: تُدمج في `/matches` و`/fixtures` و`/results` و`/live` وصفحة المباراة وخريطة الموقع (المنشور فقط). بيانات المزوّد لا تُعدَّل أبدًا.
- **الفرق / اللاعبون / البطولات / الأخبار اليدوية**: تظهر في قوائمها وصفحاتها التفصيلية وخريطة الموقع (المنشور فقط). الخبر اليدوي يتطلب اسم مصدر ورابطًا أصليًا `https`.

## الاختبار
- `npm run admin:test` — 36 اختبارًا للأدوار والجلسات وكلمات المرور وتوقيت القاهرة وقواعد البث والنشر. يعمل بالذاكرة، وبقاعدة بيانات عند ضبط `DATABASE_URL`.

## حدود معروفة
- الترتيب (`/admin/standings`) للقراءة فقط: الجداول تأتي من المزوّدين ولا تُدخل يدويًا.
- التحليلات والإعلانات (`/admin/ads`, `/admin/seo`) صفحات قديمة للعرض ولم تُربط ببيانات حقيقية بعد.
- إن تعذّرت كتابة سجل في قاعدة البيانات، تُحفظ بعض الكيانات في الذاكرة المؤقتة للعملية (السلوك الموروث من بقية المنصة)؛ أما البث فيُبلَغ المشغّل بالخطأ صراحةً.
