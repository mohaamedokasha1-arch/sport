# تحديث الدوريات تلقائيًا — NEMO Sports

**النطاق:** بيانات كرة القدم (المباريات والنتائج والبطولات التي تؤكدها المصادر)، وليس استضافة فيديو أو ضمان حقوق بث. هذا المستودع `nemo-sports` وليس مستودع البوابة المنفصلة `nemo-live-kora`.

## ما صار يعمل في الكود

- `/competitions` يعرض الدوري المصري أولًا في القائمة المعروفة، والبطولات المصرية المكتشفة حديثًا قبل بقية الإضافات. لا تُنشر بطولة مكتشفة بلا مباراة حقيقية صالحة.
- `/matches?date=today&sport=football` يجلب بيانات اليوم من المزوّد عند الطلب ويعرضها بتوقيت القاهرة؛ المتصفح يحدّث صفحة المباريات تلقائيًا. الجداول والمواعيد لها كاش/إعادة تحقق مستقلان.
- وظيفة `sports-sync/matchday` تسأل كل مصدر مُسجَّل **يدعم مباريات يوم كامل بدون تقييد ببطولة** عن كرة القدم في أيام UTC الثلاثة: يوم القاهرة الحالي، السابق، والقادم. هكذا تُسجَّل البطولات التي ظهرت في مباريات فعلية (حتى غير المدرجة يدويًا)، مع أولوية SportScore/اليوم الحالي. المهمة قصيرة وقابلة للاستئناف ولا تحذف نتيجة سابقة عند فشل المصدر. بيانات الدوريات المكتشفة تُخزَّن في PostgreSQL.
- مجدول GitHub Actions يستدعي المهمة المحمية كل **15 دقيقة تقريبًا**، وبعدها `/api/cron/sports-sync/tick` لتصريف أعمال الكتالوج والمواسم والنتائج والإحصائيات تدريجيًا. يعمل أيضًا يدويًا عبر `workflow_dispatch`؛ الجدولة قد تتأخر ولا تُضمن بالثانية.
- عندما يخبر المصدر أن رد يومه مبتور، يُسجَّل فشل واضح بدل الإيحاء بأن كل الدوريات ظهرت.

## خطوات التفعيل على الاستضافة (لا تضع القيم السرية هنا أو في المحادثة)

1. وفّر PostgreSQL دائمًا واضبط `DATABASE_URL` في بيئة الخادم، ثم نفّذ **مرة واحدة** `npm run db:setup` من بيئة تشغيل موثوقة؛ هذا يطبّق `db/migration-0007-sports-discovery.sql` والجداول المطلوبة. دون قاعدة البيانات ترفض المزامنة الدائمة العمل بدل الاعتماد على ذاكرة Vercel المؤقتة.
2. اضبط `REDIS_URL` لمخزن Redis مشترك وصالح في **الإنتاج**؛ مهمة المزامنة ترفض العمل بدونه حفاظًا على حصة الطلبات عبر نسخ Vercel. واضبط `CRON_SECRET` (أو `NEMO_INGEST_TOKEN`) على الخادم، وفعّل مصدر بيانات حقيقي: SportScore مفعّل بلا مفتاح افتراضيًا ما لم يكن `NEMO_SPORTSCORE_ENABLED=0`. بقية المصادر لا تعمل في هذه الطبقة بلا مفاتيحها المصرّح بها. لا تضبط وضع `NEMO_SDL_MODE=demo` في الإنتاج.
3. داخل إعدادات مستودع GitHub → Actions: أنشئ **Variable** باسم `NEMO_SITE_URL` يحتوي أصل الموقع فقط مثل `https://nemo-sports.vercel.app`، و**Secret** باسم `NEMO_CRON_SECRET` تطابق قيمته `CRON_SECRET` المضبوط على الخادم. لا تستخدم `?token=` ولا تسجّل السرّ في ملف أو محادثة. يستعمل المجدول ترويسة Bearer ويرفض تحويلات HTTP حفاظًا عليه.
4. ادمج التغيير في الفرع الافتراضي وانشر التطبيق: جداول GitHub Actions لا تُشغَّل من فرع العمل وحده. من تبويب Actions شغّل «League refresh» ثم «Data maintenance» يدويًا، وتأكد من حالة `matchday: success` وعدّاد المباريات؛ شغّل وضع `weekly` للصيانة إن كانت لديك مصادر فهرسة. راقب التنفيذ الدوري ومسار `/api/cron/sports-sync/status` المحمي للتحقق من `coverage` و`runs` و`issues`، وافتح `/competitions` و`/matches?date=today&sport=football`.

**Vercel Hobby:** يحافظ `vercel.json` الآن على مهمتين يوميتين فقط: الاستيعاب والأخبار في مواعيدهما الأصلية. المهام الأخرى التي كانت مجدولة فيه نقلناها **دون تغيير مساراتها أو صلاحياتها** إلى `.github/workflows/data-maintenance.yml` (مطابقة الوظائف: المباريات/الترتيب/اكتشاف المباريات يوميًا؛ مزامنة البطولات/فهرسة الـpipeline/كتالوج sports-sync أسبوعيًا). ستبدأ هذه المهام بعد الدمج في الفرع الافتراضي وضبط Variable/Secret على GitHub؛ إن لم تُضبط فلن تعمل تلقائيًا، وتفشل الـActions بوضوح بدل النجاح الوهمي. يمكن أن تتأخر مهام GitHub المجدولة عن موعدها. لا تعطل مهام Vercel المتبقية أو تحاول جدولة كل 15 دقيقة من Vercel Hobby.

**حدود التغطية:** «جميع الدوريات» تعني الدوريات التي يرجعها المزوّدون المفعّلون فعلًا للأيام التي جرى فحصها؛ لا يضمن مصدر مجاني واحد كل دوريات العالم أو جدول موسم كامل. SportScore `matches/` المباشر محدود بعينة حديثة، و`fixtures/` اليومية لها حدّ رد؛ وقد ترفض حماية المزوّد استدعاءات REST v1 من خادم Vercel. مرحّل SportScore الداخلي يدعم widget فقط **وليس** `fixtures/`، فلا تفعّله كحل زائف للاكتشاف اليومي. عالج أي فشل ظاهر في `runs` بمصدر/اتصال مُصرّح به؛ لا تُعرض نتائج مختلقة. تحتاج التغطية الأوسع مزوّدًا إضافيًا بعقد وتغطية وحصة طلبات مناسبة، ولا تطلب مفاتيحه في المحادثة.

**اختبارات محلية دون الوصول لمزوّد:** `npm run sports-sync:test && npm run leagues:refresh:test && npm run sdl:test`.
