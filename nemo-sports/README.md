# NEMO Sports · نيمو سبورتس

**Live Sports, Every Moment** — منصة رياضية شاملة متعددة الرياضات (8 رياضات) بنيت على مواصفات
المشروع الشاملة: نتائج مباشرة، أخبار، بطولات، فرق، لاعبون، بث رسمي مرخّص فقط، ولوحة تحكم.

نسخة تنفيذية (Next.js 15 + Tailwind 4 + TypeScript) تعمل ببيانات توضيحية مولّدة محليًا.

---

## التشغيل

```bash
npm install
npm run dev      # تطوير  → http://localhost:3000
npm run build    # بناء إنتاجي (209 صفحة)
npm run start    # تشغيل نسخة الإنتاج
npm run check    # فحص شامل لكل المسارات مقابل خادم يعمل
```

> `npm run check` يفترض وجود خادم على `http://127.0.0.1:3000` — يمكن تغييره بـ
> `BASE=http://… npm run check`.

## متغيرات البيئة

كل المتغيرات اختيارية — المنصة تُقلع بدونها وتتدهور بدل أن تنهار. انظر
`.env.example` للتفاصيل.

| المتغير | ماذا يفتح |
|---|---|
| `SPORTRADAR_KEY` · `SPORTMONKS_TOKEN` · `API_FOOTBALL_KEY` · `THESPORTSDB_KEY` | تفعيل المزوّد في سلسلة الأولويات؛ وأول مفتاح ينقل الوضع من `demo` إلى `live` فيعيد الفهرسة |
| `DATABASE_URL` | المخزن الكنسي الدائم في Postgres (بدونه: ذاكرة داخل العملية) |
| `REDIS_URL` | طبقات الكاش الخمس مشتركة بين النسخ (بدونه: LRU داخل العملية) |
| `NEMO_INGEST_TOKEN` | مهمة الاستيعاب؛ بدونه يرفض `/api/v1/ingest` بالعمل (503) حتى لا يُصرف رصيد مدفوع بلا حراسة |
| `NEMO_SDL_MODE` | `auto` (افتراضي) أو `demo` لإجبار المحوّل التجريبي |

```bash
cp .env.example .env.local   # ثم املأ ما لديك
npm run db:setup             # يتطلب psql + DATABASE_URL
npm run ingest football      # دورة استيعاب واحدة
```

### طبقة بيانات الرياضة (Sports Data Layer)

`packages/sdl` حزمة TypeScript مستقلة، **صفر تبعيات تشغيلية**، و71 اختبار وحدة:

```
الواجهة ──► lib/sdl-gateway.ts ──► SportsDataLayer
                                     │  أولويات → محوّل → تطبيع → كاش → حدود معدل → كيان كنسي
                                     ├── Sportradar      (x-api-key · soccer v4)
                                     ├── Sportmonks      (Bearer · v3 · include/pagination)
                                     ├── API-Football    (x-apisports-key · v3 envelope)
                                     ├── TheSportsDB     (X-API-KEY · صور وميتاداتا فقط)
                                     └── demo            (بلا مفاتيح · للتشغيل والاختبار)
```

- **لا يخرج أي شكل خاص بمزوّد**: المحوّلات تُعيد أنواع `Normalized*` فقط.
- **المعرّفات الكنسية مقدّسة**: الربط الخاطئ يُصحَّح بنقل الربط لا بحذف الكيان.
- **لا نقطة فشل واحدة**: عند فشل كل المزوّدين تُعرض آخر قيمة صالحة داخل `staleGrace`
  مع `stale: true` بدل الخطأ.
- **كل استدعاء مبرَّر**: كاش ← فحص حدود ← دمج الطلبات المتطابقة ← ثم الشبكة،
  و`costReport()` يسجّل `avoided` أي ما تجنّبناه عمدًا.
- **الصراعات**: النتيجة/الحالة/الترتيب = المزوّد الأساسي يفوز، وما يُرفض لا يُكتب أبدًا
  بل يبقى في طابور المراجعة حتى قرار المحرّر.
- التوثيق الكامل وطريقة إضافة مزوّد أو نوع بيانات جديد: `packages/sdl/README.md`.

### محرك النتائج المباشرة
`lib/live.ts` **يشتق** الحالة من الزمن الحقيقي منذ انطلاق المباراة بدل تخزينها:

- كرة القدم: `دقيقة'` · `45'–47' = الاستراحة` · `90+X'` · `انتهت` بعد 94.
- كرة السلة: `الربع n · mm:ss` · التنس: المجموعات · اليد: شوطين · الهوكي/البيسبول/الملاكمة لكل منها ساعة.
- الأحداث تظهر تدريجيًا عندما تصل الدقيقة الخاصة بها — ترى الهدف يحدث أمامك.
- `GET /api/live` (كل الحالات) · `?ids=M101` (مباراة واحدة) · `?scope=rail` (شريط الهيدر).
- العميل يعيد الجلب كل 5 ثوانٍ (4 في صفحة المباراة) دون إعادة تحميل، وعند الفشل تبقى آخر
  نتيجة معروفة على الشاشة.
- في الإنتاج: WebSocket + delta updates + Redis.

## 3. الامتثال القانوني (مطبّق في الكود لا في الكلام)

- **لا إعادة بث**: البث إما embed من نطاق الناقل أو رابط خارجي بوسم `rel="noopener noreferrer nofollow"`.
- **الإفصاح**: اسم الناقل + نوع الترخيص + المناطق + حالة البث ظاهرة قبل الضغط.
- **الحظر الجغرافي**: تنبيه صريح بالمناطق المسموح بها.
- **عند عدم وجود ناقل**: لا يُعرض أي زر، بل رسالة «البث غير متاح».
- **سجل الترخيص**: `broadcastPartners` بحالة `approved / pending / rejected` — المعلق لا يظهر للزوار.
- **الأخبار الخارجية**: ملخص أصلي + اسم المصدر + رابط بوسم nofollow (`kind: "external"`).
- **الشعارات**: monograms من تصميمنا، لا شعارات مملوكة للغير.
- **الإعلانات**: مواضع معلّمة + وسم «محتوى برعاية» + قاعدة `rel="sponsored"`.
- `robots.txt` يحجب `/admin` و`/account` و`/api/`.

## 5. ما هو منفَّذ / ما هو غير موصول

| منفَّذ ويعمل | غير موصول بعد |
|---|---|
| كل الصفحات والتبويبات والفلاتر | المصادقة والحسابات و2FA |
| محرك مباشر + شريط نتائج + تحديث دوري | WebSocket ودفع الإشعارات |
| بحث فوري بالعربية + صفحة نتائج | الدفع والاشتراكات وشبكة الإعلانات |
| SEO كامل + sitemap + JSON-LD | تطبيق الهاتف |
| لوحة تحكم بواجهاتها الكاملة (8 أقسام) | توصيل بقية الصفحات بطبقة البيانات (الآن `/live` فقط يُغذَّى من SDL) |
| وضع داكن + RTL + تجاوب + وصولية أساسية | إصدار v2 عند أول تغيير كاسر |
| **طبقة بيانات كاملة**: 4 محوّلات موثَّقة + تطبيع + مطابقة ضبابية + صراعات + كاش + حدود + صحة + فشل تلقائي | تشغيل الطبقة على مفاتيح حقيقية (المحوّلات مكتوبة على الوثائق الرسمية وتنتظر أول تغذية حية للتحقق) |
| **عقد API مُصدَّر** `/api/v1/*` (live · matches · system · ingest) | — |
| **مخطط قاعدة البيانات الكنسي** `db/schema.sql` + `db/seed.sql` | — |
| **Postgres كـ`CanonicalStore`** (`packages/sdl/src/pg-store.ts` + `lib/db/pg.ts`) | تطبيق المخطط على خادم حقيقي (`npm run db:setup`) |
| **Redis كـ`KvStore`** (`packages/sdl/src/redis-store.ts` + `lib/cache/redis.ts`) | خادم Redis فعلي (`REDIS_URL`) |
| **مهمة الاستيعاب** `/api/v1/ingest` + `npm run ingest` (محمية برمز) | جدول cron على الخادم |
| **وسم `noindex` تلقائي في وضع demo** (§Instruction 6) | — |
